UniversityApi

О проекте

UniversityApi — веб-API для управления основными данными университета. Система объединяет работу со студентами, преподавателями, учебными курсами и записями на обучение в одном приложении.

Проект позволяет выполнять основные операции с данными: добавлять новые записи, просматривать информацию, редактировать и удалять существующие данные. Также предусмотрены фильтрация учебных курсов, проверка корректности вводимой информации и предотвращение повторной записи одного студента на один и тот же курс.

Основные возможности

Управление студентами: создание, просмотр, редактирование и удаление информации.

Управление преподавателями: работа с данными преподавателей.

Управление курсами: добавление и изменение курсов, а также фильтрация по преподавателю и количеству кредитов.

Запись на курсы: создание и управление записями студентов, включая обновление оценок.

Обработка ошибок: проверка входных данных, обработка конфликтов и возврат ответов в едином формате.

API ENDPOINTS

1. STUDENTS (Студенты)

GET     /api/Students          — Получить список студентов
GET     /api/Students/{id}     — Получить студента по ID
POST    /api/Students          — Добавить нового студента
PUT     /api/Students/{id}     — Обновить данные студента
DELETE  /api/Students/{id}     — Удалить студента


2. TEACHERS (Преподаватели)

GET     /api/Teachers          — Получить список преподавателей
POST    /api/Teachers          — Добавить преподавателя
PUT     /api/Teachers/{id}     — Обновить данные преподавателя
DELETE  /api/Teachers/{id}    — Удалить преподавателя


3. COURSES (Учебные курсы)

GET     /api/Courses           — Получить список курсов
POST    /api/Courses           — Создать новый курс
PUT     /api/Courses/{id}      — Обновить информацию о курсе
DELETE  /api/Courses/{id}     — Удалить курс


4. ENROLLMENTS (Записи на курсы)

GET     /api/Enrollments       — Получить список записей
GET     /api/Enrollments/{id}  — Получить запись по ID
POST    /api/Enrollments       — Записать студента на курс
PUT     /api/Enrollments/{id}  — Обновить оценку студента
DELETE  /api/Enrollments/{id} — Удалить запись

Архитектура приложения

Проект построен на основе многоуровневой архитектуры. Каждый компонент отвечает за свою часть работы, что упрощает поддержку и развитие приложения.

        Client (Swagger / HTTP)
                 |
                 v
             Controller
                 |
                 v
              Service
                 |
                 v
             Repository
                 |
                 v
       Entity Framework Core
                 |
                 v
          SQL Server Database

Назначение основных компонентов:

Controller — принимает HTTP-запросы и возвращает ответы клиенту.

Service — содержит логику обработки запросов.

Repository — отвечает за взаимодействие с данными.

Entity Framework Core — обеспечивает работу с базой данных через объекты C#.

SQL Server — хранит информацию о студентах, преподавателях, курсах и записях на обучение.

Используемые технологии

C# и ASP.NET Core Web API

Entity Framework Core

Microsoft SQL Server

Swagger / OpenAPI
